# Patient List

Source: HackerRank Style Unit 2 Assessment, Version B

## Question

Write a function get_patients() that takes in the name of a doctor doctor and a dictionary patients that
maps patients to doctors , and returns a list of all patients of that doctor.

Example 1:
Input: doctor = "Dr. Grey", patients = { "Jane Doe": "Dr. Grey", "John Doe": "Dr. Bailey",
"Alexandra Stevens": "Dr. Grey", "Paulo Freire": "Dr. Stevens"}
Output: ["Jane Doe", "Alexandra Stevens"]
Example 2:
Input: doctor = "Dr. Banner", patients = {"Ethan Hunt": "Dr. Banner",
"James Bond": "Dr. Banner", "Bruce Wayne": "Dr. Banner"}
Output: ["Ethan Hunt", "James Bond", "Bruce Wayne"]
