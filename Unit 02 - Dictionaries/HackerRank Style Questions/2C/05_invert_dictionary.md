# Invert Dictionary

Source: HackerRank Style Unit 2 Assessment, Version C

## Question

Implement a function invert_dictionary() that inverts a dictionary, swapping its keys with its values.
Assume all values are unique and can be used as dictionary keys.

Example 1:
Input: {'apple': 1, 'banana': 2, 'cherry': 3}
Output: {1: 'apple', 2: 'banana', 3: 'cherry'}
Example 2:
Input: {4: 'cat', 5: 'dog', 6: 'fish'}
Output: {'cat': 4, 'dog': 5, 'fish': 6}
