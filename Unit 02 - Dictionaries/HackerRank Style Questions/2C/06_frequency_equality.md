# Frequency Equality

Source: HackerRank Style Unit 2 Assessment, Version C

## Question

Write a function that takes two lists of integers and determines if each unique value in the first list occurs
an equal number of times as the same value in the second list. The function should return True if the two
lists have the same frequency distribution, and False otherwise.

# Input: lst1 = [1, 2, 3, 4, 4, 5], lst2 = [2, 3, 1, 4, 4, 5]
# Output: True
# Input: lst1 = [0, 0, 1, 1, 2, 2, 3, 3], lst2 = [0, 0, 2, 2, 1, 1, 3, 5]
# Output: False
