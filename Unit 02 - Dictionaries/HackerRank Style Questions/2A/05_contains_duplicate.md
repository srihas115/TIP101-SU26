# Contains Duplicate

Source: HackerRank Style Unit 2 Assessment, Version A

## Question

Given an integer list nums, return True if any value appears at least twice in the list, and return False if
every element is distinct.

Example 1:
Input: [1, 2, 3, 1]
Output: True
Example 2:
Input: [1, 2, 3, 4]
Output: False
