# Check if Binary Tree is Perfect

Source: HackerRank Style Unit 9 Assessment, Version A

## Question

Given the root of a binary tree, return True if the binary tree is perfect and False otherwise. A binary
tree is perfect if all internal (non-leaf) nodes have two children and all leaves are at the same level.
Example Input Tree #1:
      5
     / \
    /   \
   3     6
  / \   / \
 2   4 7   8
Example Input: root = 5
Expected Output: True
Example Input Tree #2:
      5
     / \
    /   \
   3     6
  / \
 2   4
Example Input: root = 5
Expected Output: False
