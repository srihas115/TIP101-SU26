# HackerRank Style Problem Set Solution Validator

This folder is scoped to the HackerRank Style questions copied from the original HackerRank Style PDF reports.

- `solutions/` contains the submitted Python code extracted from each coding question.
- `metadata/HackerRank Style questions.json` maps every question to its prompt and solution file.
- `testpacks/HackerRank Style questions.json` mirrors that same HackerRank Style-only index.
- The shared validator engine files are copied from `ProblemSetSolutionValidator[DO_NOT_EDIT]` for parity, while regular course testpacks are intentionally not copied here.
