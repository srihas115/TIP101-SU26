# Linked List Cycle

Source: HackerRank Style Unit 10 Assessment, Version A

## Question

Given the head of a linked list, return True if the list has a cycle in it and False otherwise. A linked list has
a cycle if at some point in the list, the node's next pointer points back to a previous node in the list.

Example:
Input List
1 -> 2 -> 3 -> 4
     ▲          │
     └─────────┘
Input: head = 1
Output: True
