# Longest Palindrome

Source: HackerRank Style Unit 10 Assessment, Version A

## Question

Given a string s which consists of lowercase or uppercase letters, return the length of the longest
palindrome that can be built with those letters. Letters are case sensitive. For example "Aa" is not
considered a palindrome, but "aa" is.
Example #1:
Input: s = "abccccdd"
Output: 7
Explanation: The longest palindrome that can be built is "dccaccd", whose length is 7.

Example #2:
Input: s = "a"
Output: 1
Explanation: The longest palindrome that can be built is "a", whose length is 1.
