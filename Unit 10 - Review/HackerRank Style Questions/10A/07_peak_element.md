# Peak Element

Source: HackerRank Style Unit 10 Assessment, Version A

## Question

A peak element is an element that is strictly greater than its neighbors.

Given a list of integers nums, find a peak element, and return its index. If the list contains multiple peaks,
return the index to any of the peaks.
You may imagine that nums[-1] = nums[n] = -∞. In other words, an element is always considered to be
strictly greater than a neighbor that is outside the list.

Example #1:
Input: nums = [1,2,3,1]
Expected Output: 2
Explanation: 3 is a peak element and has index 2.
Example #2:
Input: nums = [1,2,1,3,5,6,4]
Expected Output: 5
1 is also an acceptable output
Explanation: 2 which has index 1 and 6 which has index 5 are both peak elements
