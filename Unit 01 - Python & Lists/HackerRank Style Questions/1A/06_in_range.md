# In Range

Source: HackerRank Style Unit 1 Assessment, Version A

## Question

Given a list of integers nums, a minimum value min_val, and a maximum value max_val, write a function
that returns a list of values in nums that are greater than min_val and less than max_val.
Example 1:
Input: nums = [1, 2, 3, 4, 5], min_val = 1, max_val = 5
Output: [2, 3, 4]
Example 2:
Input: nums = [8, 6, 4], min_val = 2, max_val = 10
Output: [8, 6, 4]
