# String Search

Source: HackerRank Style Unit 7 Assessment, Version A

## Question

Given an alphabetically sorted list of strings names and a string val, return the index of the first
occurrence of val in O(log n) time.
If val is not a name in names, return -1.
You may not use the built-in index() function.
Example 1:
Input: names = ['Amal', 'Beric', 'Florin', 'Julie', 'Qin'], val = 'Julie'
Output: 3
Example 2:
Input: names = ['Amal', 'Beric', 'Florin', 'Julie', 'Qin'], val = 'Tabrez'
Expected Output: -1
