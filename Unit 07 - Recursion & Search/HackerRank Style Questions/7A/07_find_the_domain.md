# Find the Domain

Source: HackerRank Style Unit 7 Assessment, Version A

## Question

Given a list of integers nums sorted in non-decreasing order, find the starting and ending position of a
given target value. Return the result as a list in the form [start_position, end_position].

If target is not found in the list, return [-1, -1]. Your solution must have O(log n) time complexity.
Example 1:
Input: nums = [5,7,7,8,8,10], target = 8
Output: [3,4]
Example 2:
Input: nums = [5,7,7,8,8,10], target = 6
Output: [-1,-1]
