# Sum the Nodes

Source: HackerRank Style Unit 8 Assessment, Version A

## Question

Given the root of a binary tree, return the sum of all its nodes' values.
You may assume all values are integers.
Example Input Tree:
"""For example:
     1
      \
       2
      /
     3
"""
Input: root = 1
Expected Output: 6
Input: root = None
Output: 0
Example Input Tree
""" 1 """
Input: root = 1
Output: 1
