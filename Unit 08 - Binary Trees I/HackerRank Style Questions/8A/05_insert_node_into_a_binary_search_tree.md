# Insert Node into a Binary Search Tree

Source: HackerRank Style Unit 8 Assessment, Version A

## Question

Given the root of a binary search tree, insert a node with the value val into the tree. Return the root.

Example Input Tree:
     3
    / \
   2   4
Input: root = 3, val = 5
Expected Output: root = 3
     3
    / \
   2   4
        \
         5
