# Palindrome Verification

Source: HackerRank Style Unit 3 Assessment, Version C

## Question

Write a function named is_palindrome that checks whether a given string is a palindrome. The function
should consider only alphabet characters and ignore case sensitivity and spaces. It returns True if the
string is a palindrome and False otherwise.
Constraints:
The input string may contain alphabets, numbers, and symbols.
Ignore spaces, numbers, punctuation, and case sensitivity.
The comparison should focus only on alphabet characters.

# Input: "Was it a car or a cat I saw"
# Output: True
# Input: "race a car"
# Output: False
