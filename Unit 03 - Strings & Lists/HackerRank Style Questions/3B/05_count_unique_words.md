# Count Unique Words

Source: HackerRank Style Unit 3 Assessment, Version B

## Question

Write a function that takes a string of words separated by spaces and returns the count of unique words
in the string. The comparison should be case-insensitive (i.e., 'Apple' and 'apple' are considered the same).
Constraints: The input string will only contain alphabet letters and spaces.

# Input: "Same same same"
# Output: 1
# Input: "The quick brown fox jumps over the lazy dog"
# Output: 8
